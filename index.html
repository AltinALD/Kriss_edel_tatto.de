Die Geschichte

Schmuck fürs Leben.

Manche Dinge legt man in eine Schatulle. Einen Ring, eine Kette, etwas, das man am Abend wieder abnimmt. Eine Tätowierung bleibt. Kristina Edel zeichnet in Köln genau dafür.

An der Sudermanstraße, im Studio 22 Tattoo Cologne, beginnt es selten mit einem fertigen Bild. Jemand kommt mit einer Blume, einer Waage, einem Ornament, einem Wort, das schon lange mitläuft. Kristina hört zu. Sie legt das Motiv zuerst auf Papier — Mandala und Pfingstrose, eine Vase voller Blätter, eine feine Linie, Schwarz und Grau, das auf der Haut ruhig stehen bleibt. Erst dann setzt sie die Nadel.

Die Linie folgt dem Körper. Der Rundung einer Schulter. Der Länge eines Unterarms. Dem Licht, das am Nachmittag durchs Studio fällt. Nichts kommt von der Stange. Jedes Stück ist für eine Haut gezeichnet, für eine Stelle, für eine Bedeutung, die nur diese Person kennt.

Das Studio ist dunkel und sauber, eher Galerie als Laufkundschaft. Wer kommt, kommt nach Absprache. Kristina nimmt sich die Zeit, das Motiv zu verstehen, bevor es bleibt. Was heilt, soll sich anfühlen wie ein Schmuckstück, das man nie wieder abnimmt.

Arbeit

Gezeichnet für eine Haut.

Ornament, Botanik und feine Linie — gesetzt, damit es bleibt.

Stil

Was hier entsteht.

Schwarz-Grau

Schatten statt harter Kante. Blätter, Schuppen und Blüten, die auf der Haut ruhig bleiben.
